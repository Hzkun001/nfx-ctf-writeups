# Medium

[Kembali ke indeks utama](../README.md)

Writeup challenge dengan difficulty **Medium** pada platform NFX CTF.
Daftar challenge belum dipetakan karena difficulty belum dikonfirmasi.

Gunakan satu folder per challenge dan tambahkan tautannya di sini setelah
writeup tersedia. Format baris indeks: nama challenge, kategori teknis,
tautan writeup, dan status verifikasi.
